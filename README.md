# KTTA of DC 홈페이지

워싱턴DC 한인탁구협회(Korean Table Tennis Association of DC) 홈페이지입니다.
Next.js 16 · React 19 · Tailwind CSS 4 로 만들었고, 글 내용과 사진·동영상은 Supabase 에 저장합니다.

## 실행하기

Node.js 20.9 이상이 필요합니다.

```bash
npm install     # 처음 한 번만
npm run dev     # http://localhost:3000
```

처음 실행하기 전에 `.env.example` 을 `.env.local` 로 복사하고 Supabase 주소·키와 관리자 비밀번호를 채워 주세요.
([Supabase 연결](#supabase-연결) 참고. 값이 없으면 페이지가 열리지 않고 어떤 값이 빠졌는지 알려 줍니다)

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버. 수정한 내용이 바로 반영됩니다. |
| `npm run build` 후 `npm start` | 실제 배포와 같은 방식으로 실행합니다. |
| `npm run lint` | 코드 검사 |

## 페이지 구성

| 주소 | 내용 |
| --- | --- |
| `/` | 홈 — 메인 화면(동영상·이미지 또는 배너), 인사말, 대회 정보, 갤러리 미리보기 |
| `/about` | 협회 소개 — 협회장 인사말, 임원진, 정관(PDF) |
| `/tournaments` | 대회 정보 — 예정된 대회 / 지난 대회(연도별) |
| `/tournaments/[id]` | 대회 상세 — 일시·장소·참가 안내, 포스터, 첨부 파일 |
| `/tournaments/[id]/bracket` | 실시간 대진표 — 내 경기 찾기, 테이블 현황, 조별 리그, 본선 대진표, 점수 입력 (누구나) |
| `/games` | 번개 게임 — 새 게임 만들기, 이름으로 기록 찾기, 최근 게임 (대회와 상관없이 누구나) |
| `/games/new`, `/games/[id]` | 번개 게임 만들기와 게임 화면 — 순위표, 경기 목록·경기 기록, 테이블(선택), 점수 입력 |
| `/gallery`, `/gallery/[id]` | 갤러리 — 앨범 목록과 사진·동영상 (사진을 골라 한꺼번에 내려받기) |
| `/community/news`, `/community/news/[id]` | 탁구 소식 — 신문 기사, 회원 안내 글 목록과 본문 |
| `/community` | 탁구 장소 |
| `/community/etiquette` | 탁구 에티켓 |
| `/admin` | 관리자 홈 — 다음 대회 대진표 바로가기, 메인 화면·대회 정보·갤러리 앨범·탁구 소식을 카드로 요약 |
| `/admin/tournaments`, `/admin/albums`, `/admin/news` | 관리자 — 대회·앨범·소식 목록 (검색, 필터, 등록, 수정, 숨김, 삭제) |
| `/admin/draws` | 관리자 — 대진표 목록 (다가오는 대회와 대진표를 만든 지난 대회, 진행 상태, 체크인 바로가기) |
| `/admin/tournaments/[id]/draw` | 관리자 — 대진표 관리 (선수 명단, 종목, 참가 팀, 조 편성, 대진 확정, 테이블 수) |
| `/admin/tournaments/[id]/checkin` | 관리자 — 대회 날 접수 데스크의 선수 체크인 |
| `/admin/hero` | 관리자 — 메인 화면 동영상·이미지 올리기, 순서, 숨김, 삭제 |
| `/admin/games` | 관리자 — 번개 게임 목록과 저장된 이름 (장난으로 만든 게임·잘못 들어간 이름 지우기) |
| `/rss.xml` | 대회 정보·탁구 소식 RSS 피드 (검색 사이트 제출용) |

관리자 화면을 뺀 모든 페이지는 주소 앞에 `/en` 을 붙이면 영어로 나옵니다. (`/en`, `/en/about`, `/en/tournaments/[id]` …)

## 한국어 · 영어

헤더의 **관리자 버튼 왼쪽에 있는 동그란 국기 버튼**을 누르면 보고 있던 페이지가 다른 언어로 바뀝니다.
버튼에는 바꿀 언어의 국기가 보입니다. 한국어 화면에는 성조기(영어로 보기), 영어 화면에는 태극기(한국어로 보기)입니다.

- 주소가 `/` 로 시작하면 한국어, `/en` 으로 시작하면 영어입니다. 방문자의 브라우저 언어에 따라 자동으로 바뀌지는 않습니다.
- 관리자 화면은 한국어만 있습니다.
- 영어 문장은 한국어를 그대로 옮기지 않고, 영어권 방문자가 읽기 편하게 짧고 정중하게 씁니다.

영어 글은 종류에 따라 넣는 곳이 다릅니다.

| 종류 | 넣는 곳 |
| --- | --- |
| 메뉴·버튼·제목 같은 화면 문구 | `lib/i18n/dictionaries/ko.ts` 와 `en.ts` 의 같은 자리 |
| 인사말·임원진, 탁구 장소, 탁구 에티켓 | `lib/content/` 의 각 항목에 `{ ko: "…", en: "…" }` 으로 나란히 |
| 대회 정보·갤러리·탁구 소식 | 관리자 입력 화면의 **영어 화면용 (English)** 칸 |

- 관리자 화면의 영어 칸은 비워 두어도 됩니다. 비워 둔 칸은 영어 화면에도 한국어 글이 그대로 나옵니다.
- 대회의 **요강 요약 (영어)** 에는 포스터를 통째로 번역하지 말고 종목·방식·참가비·신청 방법만 간추려 적습니다.
  포스터가 한국어이므로 영어 화면에서는 이 글이 펼쳐진 채로 보입니다.
- 날짜·시간·“D-12” 같은 표시는 언어에 맞게 자동으로 바뀝니다. (`lib/dates.ts`)
- 사람 이름은 본인이 쓰는 영문 이름을 적고, 모를 때는 로마자 표기 뒤에 한글 이름을 괄호로 함께 적습니다. (예: `Sunkwon Kim (김선권)`)

## 대회 정보 올리기

1. 홈페이지 맨 위(휴대폰에서는 메뉴 안)나 맨 아래의 **관리자**를 누르거나 주소 뒤에 `/admin` 을 붙여 접속한 뒤, 관리자 비밀번호로 로그인합니다.
   (예: `https://www.kttaofdc.org/admin` — 휴대폰에서도 됩니다)
2. 위쪽 탭에서 **대회 정보**를 고르고 **새 대회 등록**을 눌러 대회 이름·날짜·장소 등을 적고, 포스터 이미지와 요강 파일(PDF 등)을 올립니다.
3. 저장하면 대회 정보 페이지와 홈 화면에 바로 나타납니다. 날짜가 지나면 자동으로 ‘지난 대회’로 넘어갑니다.

- 관리자 비밀번호는 Vercel 의 **Settings → Environment Variables** 에 있는 `ADMIN_PASSWORD` 입니다. 바꾼 뒤에는 다시 배포(Redeploy)해야 적용됩니다.
  (내 컴퓨터에서 실행할 때는 `.env.local` 의 값을 씁니다)
- 큰 사진은 올릴 때 자동으로 긴 변 1600px 로 줄어듭니다.
- 갤러리는 **갤러리 앨범** 탭의 **새 앨범 만들기**에서 사진을 올립니다.
- 관리자 화면은 위쪽 탭(**관리 홈 · 메인 화면 · 대회 정보 · 대진표 · 번개 게임 · 갤러리 앨범 · 탁구 소식**)으로 나뉘어 있습니다.
  각 목록은 연도별로 묶여 있고, 위의 검색 칸과 **전체 · 예정 · 지난 대회 · 숨김** 같은 필터로 원하는 글을 찾습니다.
- 앨범에는 동영상도 넣을 수 있습니다 (**MP4·WEBM, 한 개에 50MB 이하**). 앨범 화면에서 사진 아래에 따로 모아 보여 주고, 누르면 그 자리에서 재생됩니다.
- 첫 번째 이미지가 대회의 대표 포스터·앨범의 표지입니다. 다른 이미지 위의 **대표로 지정**·**표지로 지정**을 누르면 그 이미지가 맨 앞으로 옵니다.
- 영어 화면(`/en`)에 보여 줄 글은 입력 화면의 **영어 화면용 (English)** 칸에 적습니다. 비워 두면 한국어 글이 나옵니다.
- 아직 준비 중인 대회·앨범·소식은 입력 화면 맨 아래의 **방문자에게 숨기기**를 체크하고 저장하면 관리자 화면에서만 보입니다.
  관리자 목록의 **보이기**·**숨기기** 버튼으로도 바로 바꿀 수 있습니다.
  (숨김은 임시 저장용입니다. 올린 사진·파일은 주소를 아는 사람이면 누구나 열 수 있으므로 공개하면 안 되는 자료를 넣어 두는 용도로는 쓰지 마세요.)
- 방문자는 앨범 화면의 **사진 내려받기**로 사진을 골라 받을 수 있습니다. 여러 장은 ZIP 파일 하나로 묶입니다.

## 대진표 운영하기

대회 날 참가 선수로 예선 조를 나누고, 누구나 휴대폰으로 점수를 입력하면 순위·본선이 저절로 정해집니다.

1. 관리자 화면의 **대진표** 탭에서 그 대회의 **대진표 관리**를 누릅니다. 처음이면 **대진표 만들기**를 누릅니다.
   관리 홈 맨 위 카드에서 다음 대회의 대진표·체크인으로 바로 갈 수 있고, 대회 정보 목록의 **대진표** 버튼으로도 들어갈 수 있습니다.
2. **대회장 설정**에서 테이블 수를 정합니다. 0으로 두면 테이블 없이 진행합니다.
   **체크인 사용**을 켜 두면(기본) 대회 날 도착한 선수만으로 대진을 확정합니다.
3. **선수 명단**에 신청한 선수를 한 줄에 한 명씩 올립니다: `홍길동, 650, KCPC` (이름, 레이팅, 소속 — 레이팅·소속은 빼도 됩니다)
4. **종목**을 만듭니다. (예: 복식 U1000 · 5게임 3선승 · 한 조 4팀 · 조 1·2위 본선)
   **경기 방식**은 예선과 본선을 따로 정할 수 있습니다. 본선을 예선과 다르게 고르고 **언제부터**에서 본선 처음부터·16강·8강·준결승부터·결승만 가운데 고릅니다.
   (예: 예선 3세트 2선승, 8강부터 5세트 3선승) 경기를 시작한 뒤에도 바꿀 수 있지만, 방식이 바뀌는 라운드에 점수가 들어간 경기가 있으면 바뀌지 않습니다.
5. 종목마다 **참가 팀**을 넣습니다. 명단에서 두 사람을 골라 **팀 넣기**를 누르거나, **붙여 넣기로 한꺼번에 바꾸기**에
   `홍길동 / 김철수, 600, 500, KCPC` 처럼 한 줄에 한 팀씩 붙여 넣습니다. 붙여 넣은 이름은 명단에도 저절로 올라갑니다.
   팀 레이팅은 두 사람의 레이팅을 더한 값입니다.
6. **조 편성 만들기**로 미리 조를 나눠 둡니다. 레이팅이 높은 순서로 A조부터 지그재그로 나누고, 같은 소속은 되도록 다른 조에 넣습니다.
   한 조에 4팀이 원칙이고 나누어떨어지지 않으면 3팀 조가 생깁니다. 각 팀의 **옮기기**로 조를 바꿀 수 있습니다.
7. 대회 날 접수 데스크에서 **체크인 화면**(`/admin/tournaments/[id]/checkin`, 관리자 로그인 필요)을 열고 도착한 선수의 이름을 누릅니다.
   데스크가 여러 곳이어도 5초마다 서로 맞춰집니다. 당일 신청한 선수도 이 화면에서 명단에 올릴 수 있습니다.
   선수가 모두 왔으면 대진표 관리의 **선수 명단**에서 **모두 도착**을 눌러 한 번에 표시할 수 있습니다 (**모두 도착 전으로**는 그 반대).
8. 종목의 **체크인 확인과 대진 확정**에서 아직 오지 않은 팀을 **빼기** 또는 **기다리기**로 고르고 **대진 확정하고 경기 시작**을 누릅니다.
   - 빼는 팀은 대진에서 빠지고, 미리 만든 조에서 그 자리만 빕니다. 빈자리 때문에 한 조가 너무 작아지면(4팀 조 기준 2팀 이하) 그 종목의 조를 다시 나눕니다.
   - 기다리는 팀은 조에 남고, 도착을 확인할 때까지 그 팀의 경기는 시작할 수 없습니다.
   - 한 명만 온 팀은 **선수 바꾸기**로 명단의 다른 선수와 짝을 지어 줄 수 있습니다.
   - 확정하면 조마다 테이블이 하나씩 정해집니다 (경기가 남은 조가 가장 적은 테이블부터, 조가 테이블보다 많으면 두 조가 나눠 씀).
     종목 화면의 **조별 테이블**에서 바꿀 수 있습니다. 대회 상세 페이지에 **실시간 대진표** 안내가 나타납니다.

대회 중에는 이렇게 돌아갑니다.

- 방문자 화면(`/tournaments/[id]/bracket`)은 5초마다 저절로 새로 고쳐집니다. **내 경기 찾기**에 이름을 넣으면 지금 몇 번 테이블에서 경기 중인지, 다음 경기를 몇 번 테이블에서 치는지, 다음 상대가 누구인지 보여 줍니다. 찾은 팀을 **내 팀으로 저장**하면 그 휴대폰이 기억했다가 다음에 열 때 이름을 넣지 않아도 바로 보여 주고, 마지막으로 본 탭도 기억합니다.
- **테이블 현황**의 카드마다 그 테이블을 쓰는 조와 남은 경기가 나옵니다. 조 안의 경기는 아무 순서로나 칩니다.
  카드의 **경기 시작**을 눌러 칠 경기를 고르면 모두의 화면에 경기 중으로 보입니다. 누구나 할 수 있습니다. 누르지 않고 점수만 넣어도 되고, 점수가 들어간 경기는 그 조의 테이블에서 경기 중으로 보입니다.
  관리자 화면에서는 경기를 누른 점수 입력 창에서도 **N번 테이블에서 시작**을 누를 수 있습니다 (방문자 창에는 없어 선수는 바로 점수를 적습니다). 시작만 누르고 점수가 없는 경기가 있는 테이블에서 다른 경기를 시작하면, 원래 경기는 대기로 돌아갑니다.
- 맡은 조가 없거나 조 경기가 끝난 테이블은 **빈 테이블**입니다. **경기 시작**을 누르면 지금 칠 수 있는 경기(본선 경기 먼저, 그다음 오래 기다린 순서)를 골라 그 테이블에서 시작합니다. 4팀 조가 두 경기를 동시에 칠 때도 이렇게 씁니다.
- **본선 대진표**에서는 상대가 정해지고 아직 시작하지 않은 경기 칸 아래에 지금 빈 테이블 번호가 나옵니다. 번호를 누르면 그 테이블에서 시작하고, 칸 위에 **N번 테이블**이 보입니다. 누구나 할 수 있습니다.
  잘못 눌렀으면 그 경기를 눌러 점수 입력 창 제목의 테이블 표시에서 다른 테이블로 옮기거나, 점수를 넣기 전이면 **배정 취소**를 누릅니다.
- 경기가 끝나도 그 테이블에 다음 경기를 저절로 올리지 않습니다. 선수가 다른 테이블에서 경기 중이거나 도착 확인 전인 팀이 있는 경기는 시작할 수 없습니다 (점수 입력은 됩니다).
- 경기를 누르면 누구나 **게임별 점수**(11-7, 9-11 …), **게임 수만**(3:1), **기권** 가운데 골라 입력합니다. 게임이 끝날 때마다 저장하면 진행 상황이 모두에게 보입니다.
- 조 경기가 모두 끝나면 순위(승수 → 두 팀이 같으면 승자승 → 세 팀 이상이 같으면 그 팀들끼리의 승수·게임 득실·점수 득실)가 정해지고 본선 자리가 채워집니다.
  조 1위는 시드 자리에, 같은 조 2위는 반대쪽에 놓이고, 빈 자리는 부전승입니다. 3위 결정전 없이 준결승에서 진 두 팀이 공동 3위입니다.
- 두 사람이 같은 경기에 점수를 넣으면 뒤에 저장한 사람에게 "그 사이 다른 분이 입력했습니다"라고 알리고 덮어쓰지 않습니다.
  다음 경기가 이미 시작되어 상대가 바뀌게 되는 수정은 받지 않습니다.

관리자 화면의 **경기 진행**은 방문자 화면과 같고, 경기를 누르면 점수 수정 외에 **결과 지우기**를 할 수 있고, 제한 없이 아무 테이블에나 올리거나 내릴 수 있습니다.
**입력 기록** 탭에서 누가 언제 어떤 결과를 넣었는지(관리자 입력 여부 포함) 확인합니다.

- 방문자 점수 입력은 대회 다음 날이 지나면 저절로 막힙니다. 그 전에 막으려면 **누구나 점수 입력** 체크를 풀고 저장합니다. 관리자는 언제든 입력할 수 있습니다.
- 기다리던 팀이 끝내 오지 않거나 경기 중에 빠지면 종목 카드의 **불참 처리**를 누릅니다. 남은 경기가 모두 상대의 기권승으로 적히고 대진표가 이어집니다. 잘못 눌렀으면 **불참 취소**로 되돌립니다.
- 경기를 시작한 뒤 팀이나 조를 바꾸려면 **조 편성으로 되돌리기**를 누릅니다. 그 종목에 입력한 점수가 모두 지워지고, 확정 전의 조 편성으로 돌아갑니다.
- 대진표는 Supabase 의 `draws` 테이블에 대회 하나가 한 줄로 저장됩니다. 대회를 지우면 대진표도 함께 지워집니다.

## 번개 게임

대회가 아닌 모임·연습 때 누구나 리그전이나 경기 기록을 만들어 휴대폰으로 함께 점수를 적습니다. 로그인은 필요 없습니다.

1. 메뉴의 **번개 게임**(`/games`)에서 **새 게임 만들기**를 누릅니다.
2. 방식을 고릅니다.
   - **리그전**: 모두와 한 번씩 경기하고 순위를 냅니다. 단식·복식(고른 순서대로 두 사람씩 한 팀, **짝 무작위로**)을 고르고 세 명(팀) 이상 넣습니다.
     순위는 대회 조별 리그와 같은 규칙이고, 모든 경기가 끝나면 1·2·3위가 맨 위에 나옵니다.
   - **자유 기록**: 정해진 대진 없이 친 경기를 그때그때 적습니다. 참가자는 미리 넣지 않아도 되고, 경기마다 단식·복식을 고릅니다.
     순위는 한 사람씩 이긴 경기가 많은 순서, 같으면 진 경기가 적은 순서입니다 (복식은 두 사람 모두에게 셉니다).
3. 참가자 칸에 이름 몇 글자나 초성(`ㅎㄱㄷ`)만 쳐도 전에 번개 게임에 쓴 이름이 나옵니다. 누르면 들어가고, 처음 쓰는 이름은 적고 Enter 를 누릅니다.
   여러 이름을 쉼표·줄바꿈으로 한꺼번에 붙여 넣어도 됩니다. 띄어쓰기·대소문자만 다른 이름은 같은 사람으로 봅니다.
4. 경기 방식(3·5·7세트)과 테이블 수를 고릅니다. 기록만 할 때는 테이블을 **안 씀**으로 둡니다 (기본).
5. **게임 만들기**를 누르면 게임 화면이 열립니다. **링크 보내기**로 카카오톡 등에 주소를 보내면 누구나 같은 화면에서 점수를 적습니다. 5초마다 새로 고쳐집니다.

- 점수는 경기를 눌러 **이긴 쪽의 세트 스코어(3:0 · 3:1 · 3:2) 단추 하나**로 적습니다. 원하면 **세트별 점수**로 적어도 되고, 리그전은 **기권**도 있습니다.
  두 사람이 같은 경기를 동시에 고치면 뒤에 저장한 사람에게 알리고 덮어쓰지 않습니다.
- 테이블을 쓰는 게임은 위에 테이블 현황이 나옵니다. 빈 테이블의 **경기 시작**이나 경기 창의 테이블 번호로 시작하면 모두에게 경기 중으로 보이고, 점수를 넣으면 테이블이 비워집니다. 다른 테이블에서 경기 중인 선수의 경기는 시작할 수 없습니다.
- 번개 게임 홈의 **이름으로 기록 찾기**에서 이름을 고르면 그 사람이 나온 게임과 전체 성적(몇 게임 · 몇 승 몇 패)이 나옵니다.
  **내 이름으로 저장**을 누르면 그 휴대폰이 기억해서 이름 고르기 맨 앞에 '나'로 나오고, 자유 기록의 경기 기록 창에 미리 들어가며, 순위표에 '나' 표시가 붙습니다.
- 게임을 만든 휴대폰에는 **게임 관리**가 보입니다 (게임 이름·테이블 수 바꾸기, 참가자 더하기·이름 고치기·빼기, 기록 마감·다시 열기, 게임 지우기).
  **관리 링크 복사**로 받은 주소를 다른 휴대폰에서 열면 그 휴대폰에서도 관리할 수 있습니다. 관리자로 로그인한 채 게임 화면을 열어도 관리할 수 있습니다.
- 기록은 지우지 않는 한 계속 남습니다. 다만 마지막 기록 뒤 7일이 지나거나 만든 사람이 **기록 마감**을 누르면, 그 뒤로는 만든 사람(과 관리자)만 결과를 고칠 수 있습니다.
- 번개 게임 화면은 회원 이름과 성적이 나오므로 검색 사이트에 내보내지 않습니다 (`noindex`).
- 장난으로 만든 게임이나 잘못 들어간 이름은 관리자 화면의 **번개 게임** 탭(`/admin/games`)에서 지웁니다. 이름을 지워도 그 이름이 나온 게임 기록은 그대로입니다.
- 게임은 Supabase 의 `games` 테이블에 게임 하나가 한 줄로, 쓴 이름은 `game_people` 테이블에 한 사람이 한 줄로 저장됩니다. (`supabase/schema.sql`)

## 탁구 소식 올리기

커뮤니티의 **탁구 소식**에는 신문에 실린 기사나 회원들에게 필요한 안내를 올립니다.

1. 관리자 화면의 **탁구 소식** 탭에서 **새 소식 등록**을 누릅니다. (`/admin/news/new`)
2. 제목과 날짜를 적고, 내용을 쓰거나 기사를 찍은 사진을 올립니다. 둘 다 올려도 됩니다.
3. 저장하면 커뮤니티 → 탁구 소식에 최근 날짜 순으로 나타납니다.

- 신문 기사라면 **출처**에 신문 이름을, **원문 링크**에 기사 주소를 적습니다. 글 아래에 원문으로 가는 버튼이 생깁니다.
- 첫 번째 이미지가 목록에 작게 보이는 대표 이미지입니다.
- 안내문 PDF 같은 파일은 **첨부 파일**로 올리면 방문자가 내려받을 수 있습니다.

## 메인 화면 동영상 올리기

홈 화면 맨 위에는 관리자 화면에서 올린 동영상·이미지가 차례로 나옵니다. 올린 것이 없으면 기본 배너 이미지가 나옵니다.

1. 관리자 화면에서 **메인 화면** 탭을 누릅니다. (`/admin/hero`)
2. 제목(선택)을 적고 **파일 선택**으로 동영상이나 이미지를 올리면 바로 홈 화면에 나타납니다.
3. 목록의 화살표로 순서를 바꾸고, 눈 모양 버튼으로 잠시 숨기거나, 휴지통 버튼으로 삭제합니다.

- 동영상은 **MP4·WEBM, 한 개에 50MB 이하**만 올릴 수 있습니다. (홈 화면에서 자동으로 재생되므로 너무 큰 파일은 받지 않습니다)
  iPhone 으로 찍은 MOV 파일은 MP4 로 바꿔서 올려 주세요.
- 동영상은 소리가 꺼진 채 자동으로 재생되고, 방문자가 화면의 스피커 버튼으로 소리를 켤 수 있습니다.
- 동영상은 끝까지 재생한 뒤, 이미지는 5초 뒤에 다음으로 넘어갑니다. 한 개만 올리면 계속 되풀이됩니다.
- 가로로 긴 화면(16:9)에 맞춰 보여 주며, 비율이 다른 동영상·이미지도 잘리지 않습니다.

## Vercel 에 배포하기

1. 이 폴더를 GitHub 저장소로 올린 뒤, Vercel 에서 **Add New → Project** 로 그 저장소를 불러옵니다. 설정은 기본값 그대로 두면 됩니다.
2. **Settings → Environment Variables** 에 아래 값을 넣습니다. 값이 없으면 배포(빌드)가 실패합니다.
3. 도메인은 아래 **도메인 연결하기** 순서대로 붙입니다.

| 이름 | 값 |
| --- | --- |
| `SUPABASE_URL` | Supabase 프로젝트의 Project URL |
| `SUPABASE_SECRET_KEY` | Supabase 프로젝트의 Secret key |
| `ADMIN_PASSWORD` | 관리자 로그인 비밀번호. 누구나 로그인 화면에 들어올 수 있으므로 길고 추측하기 어렵게 정합니다. |
| `SESSION_SECRET` | 로그인 쿠키 서명용 값. `openssl rand -hex 32` 로 만듭니다. |
| `NEXT_PUBLIC_SITE_URL` | 홈페이지 주소 `https://www.kttaofdc.org` (아래 **도메인 연결하기** 참고) |

배포한 뒤에는 **공개 사이트의 관리자 화면에서 바로** 내용을 올리고 고칩니다. 저장하면 곧바로 사이트에 나타나며, 다시 배포할 필요가 없습니다.

- 내 컴퓨터에서 `npm run dev` 로 띄운 관리자 화면도 같은 Supabase 에 저장합니다. 다만 그렇게 고친 내용은 공개 사이트에 최대 한 시간 뒤에 반영됩니다.

## 도메인 연결하기

홈페이지 주소는 `https://www.kttaofdc.org` 입니다. `kttaofdc.org` 로 들어와도 www 주소로 넘어갑니다.

도메인은 Wix 에서 구매했고(2029-09-23 만료) DNS 도 Wix 에서 관리합니다.
Wix 에서 산 도메인은 네임서버를 바꿀 수 없어서, DNS 레코드 두 개만 Vercel 을 가리키게 합니다.

1. Vercel 프로젝트의 **Settings → Domains → Add Domain** 에 `kttaofdc.org` 를 넣습니다.
   `www.kttaofdc.org` 를 함께 추가하고 `kttaofdc.org` 를 www 로 넘기는 권장 옵션을 고릅니다.
2. Wix 의 **Domains → 도메인 옆 ⋯ → Manage DNS Records** 에서 아래 두 레코드를 Vercel 화면에 나오는 값으로 맞춥니다.

   | 종류 | Host | 값 |
   | --- | --- | --- |
   | A | 비워 둠 | Vercel 이 알려 주는 IP 주소 하나. Wix 주소(`185.230.63.x`)는 지웁니다. |
   | CNAME | `www` | Vercel 이 알려 주는 주소 (`….vercel-dns-….com`). 복사할 때 끝에 붙는 점(`.`)은 빼고 넣습니다. |

3. Vercel 의 **Settings → Environment Variables** 에 `NEXT_PUBLIC_SITE_URL` 을 `https://www.kttaofdc.org` 로 넣고 다시 배포합니다.
   링크 미리보기와 sitemap·RSS 에 적히는 주소가 이 값으로 만들어집니다.

- 레코드를 바꾸면 보통 1시간 안에 반영되고, HTTPS 인증서는 Vercel 이 자동으로 발급합니다.
- 기존 협회 사이트 `www.kttava.org` 는 별개의 Wix 도메인이라 이 설정과 상관없이 그대로 열립니다.

## 검색 사이트에 등록하기

도메인을 연결한 뒤 Google 과 네이버에서 홈페이지가 검색되도록 등록합니다.

1. [Google Search Console](https://search.google.com/search-console) 과 [네이버 서치어드바이저](https://searchadvisor.naver.com) 에 사이트 주소를 추가하고, 소유 확인 방법으로 **HTML 태그**를 고릅니다.
2. 안내에 나오는 `<meta name="..." content="○○○" />` 에서 `content` 의 값만 복사해 `lib/site.ts` 의 `verification` 에 넣습니다.
   (`google` 에는 Google 의 값, `naver` 에는 네이버의 값)
3. 커밋해서 배포한 뒤, 각 사이트에서 **확인** 버튼을 누릅니다.
4. 확인이 끝나면 사이트맵 `/sitemap.xml` 을 제출합니다. 네이버에는 RSS `/rss.xml` 도 함께 제출할 수 있습니다.

검색 결과에 보이는 제목과 설명, 검색 사이트에 알려 주는 협회 정보는 아래에서 고칩니다.

| 위치 | 내용 |
| --- | --- |
| `lib/i18n/dictionaries/` 의 `site.homeTitle` · `site.titleSuffix` | 홈 화면 제목, 다른 페이지 제목 뒤에 붙는 협회 이름 |
| `lib/site.ts` 의 `description` | 홈 화면 설명 |
| `lib/content/association.ts` 의 `homeIntro` | 홈 화면 인사말 아래의 협회 소개 글 (지역과 하는 일) |
| `lib/structured-data.ts` | 협회의 다른 이름·활동 지역, 대회 일정 (화면에는 보이지 않습니다) |

검색 순위는 다른 사이트가 이 홈페이지를 얼마나 링크하는지에 크게 좌우됩니다.
재미대한탁구협회의 워싱턴DC 페이지(`kttausa.org/dc`), 기존 홈페이지(`www.kttava.org`), 신문 기사에 `www.kttaofdc.org` 가 실리도록 요청해 두면 좋습니다.

## Supabase 연결

글 내용과 올린 파일은 협회 계정(kttaofdc@gmail.com)의 Supabase 프로젝트에 저장합니다.
(조직 **Korean Table Tennis Association of DC**, Pro 요금제, 지역 East US)
프로젝트를 새로 만들어야 할 때는 아래 순서로 연결합니다.

1. [supabase.com](https://supabase.com) 에서 **New project** 를 만듭니다. 지역은 방문자와 가까운 미국 동부(**East US**)를 고릅니다.
2. **SQL Editor** 에 [`supabase/schema.sql`](supabase/schema.sql) 의 내용을 통째로 붙여 넣고 **Run** 을 누릅니다.
   테이블 7개와 파일을 담는 `uploads` 버킷이 만들어집니다.
3. **Project Settings → API Keys** 에서 Project URL 과 **Secret key** 를 복사해 `.env.local` 과 Vercel 환경 변수에 넣습니다.
   Secret key 로는 모든 내용을 읽고 쓸 수 있으므로 다른 사람에게 보여 주지 않습니다.

저장과 관련된 코드는 `lib/store/` 에만 모여 있고, 화면과 관리자 기능은 이 파일들의 함수만 호출합니다.

| 파일 | 역할 |
| --- | --- |
| `lib/store/supabase.ts` | Supabase 연결 (서버에서만 사용) |
| `lib/store/db.ts` | 테이블을 읽고 쓰는 공통 코드 |
| `lib/store/tournaments.ts` · `albums.ts` · `news.ts` · `hero.ts` | 대회 정보 · 갤러리 앨범 · 탁구 소식 · 메인 화면 |
| `lib/store/draws.ts` | 대진표. 동시에 저장한 내용이 덮이지 않게 `version` 을 확인하며 바꿉니다. |
| `lib/store/games.ts` | 번개 게임과 쓴 이름 모음. 대진표처럼 `version` 을 확인하며 바꿉니다. |
| `lib/store/files.ts` | 업로드 파일 저장·삭제 |

- 테이블은 항목 하나가 한 줄이고, `data` 칸에 `lib/types.ts` 의 모양 그대로 들어 있습니다. 입력 칸을 늘려도 테이블을 고칠 필요가 없습니다.
- 큰 파일도 올릴 수 있도록, 파일은 서버를 거치지 않고 관리자의 브라우저에서 Supabase 로 바로 올라갑니다.
  서버(`app/api/admin/upload`)는 로그인과 파일 종류를 확인하고 한 번만 쓸 수 있는 업로드 주소를 내줍니다.
- 파일 한 개는 50MB 까지 받습니다 (`uploads` 버킷에 걸어 둔 한도). 사용량은 Supabase 대시보드의 **Usage** 에서 볼 수 있습니다.
